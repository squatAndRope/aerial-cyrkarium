# Aerial · Fundacja Cyrkarium

Serwis o aerialu w Polsce pod adresem https://aerial.cyrkarium.com: mapa studiów, kalendarz wydarzeń i ogłoszenia.

## Stan

W budowie. Strona ma `noindex`, a `robots.txt` blokuje wyszukiwarki. Oba trzeba zmienić przy starcie.

## Wdrożenie

Hostinger wdraża automatycznie gałąź `main` (webhook z GitHuba), więc każdy push na `main` od razu trafia na aerial.cyrkarium.com.
